## 简介

KizunaEngine 使用Flutter渲染运行各种视觉小说引擎。

<details>
<summary>组成</summary>

- `app`
 壳

- `engine`
 运行核心

- `kernel`
 引擎核心
 
</details>

<details>
<summary>引擎支持列表</summary>

- `Bishop`
 Bishop

- `Overdose`
 aka Emon
 
</details>
